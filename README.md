# Machine Learning en Unity: células adaptativas

Proyecto Unity 6000.5.5f1 con selección evolutiva de color y tamaño, memoria de experiencias, mutación y pool de células.

- [Algoritmo, integración, parámetros, pruebas y guion de vídeo](Documentation/Adaptacion.md)
- [Código completo en bloques separados por archivo](Documentation/CodigoCompleto.md)
- [Resultados de validación](Documentation/Resultados.md)

Abre `Assets/Scenes/MainScene.unity` y pulsa Play. Las referencias existentes se mantienen; si no se asigna configuración adaptativa se usan valores predeterminados. La escena conserva su máximo original de 20 células. Para la prueba de 100 células consulta la documentación.
